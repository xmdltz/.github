This repository contains the default community health files for the [@01-edu](https://github.com/01-edu) organization on GitHub. These files provide a consistent baseline for all our projects.

## 📁 Repository Structure

- `CODE_OF_CONDUCT.md`: Our pledge for a welcoming and inclusive community.
- `SECURITY.md`: Instructions for reporting security vulnerabilities.
- `agents.md`: Special instructions for our AI assistants.
- `profile/`: Organization profile metadata and templates.
